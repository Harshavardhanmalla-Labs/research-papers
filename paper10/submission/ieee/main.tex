\section*{Data Availability Statement}
The data and code that support the findings of this study are openly
available in the research-papers repository at
\url{https://github.com/Harshavardhanmalla-Labs/research-papers/tree/main/paper10}.
The synthetic evaluation fleet, the pipeline runner, the analysis
scripts, and the frozen result tables (\texttt{autoheal\_results.csv},
2{,}700 rows, and the derived \texttt{hypothesis\_summary.json}) are
included and regenerate every reported number deterministically from
the fixed seeds.
