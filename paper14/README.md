# Patch Tuesday Triage: Asset Criticality, Not Early Exploit Signal, Drives Emergent-Risk Prioritization

Code and frozen results for the paper. At disclosure time a government patch team must
prioritize newly disclosed CVEs under capacity, when the EPSS exploit signal is still immature.
This study asks whether the early exploit estimate or the asset context of the host governs good
emergent-risk triage, using a pre-registered simulation with EPSS/KEV resampled from a frozen
real corpus and an immature day-0 observation produced by a maturation model.

## Headline result (25 fresh pre-registered seeds, 500 to 524)

| Hypothesis | Verdict | Evidence |
|---|---|---|
| H1: context-weighted triage beats context-blind day-0 EPSS by at least 5 points | SUPPORTED | +6.5 points MWP@50, interval [4.9, 7.8] (0.298 vs 0.234) |
| H2: the day-0 EPSS observation adds little | SUPPORTED | dropping it changes MWP@50 by -1.5 points |
| H3: the gain comes from asset context, not exploit-signal handling | SUPPORTED | context-off predictor 0.234, equal to blind to within 0.0 points |
| H4: the advantage is a triage-regime effect | SUPPORTED | +6.5 points at K=50, +0.1 points at K=250 |

Context-weighted triage with stable signals (0.298) nearly matches an oracle ranking by the
matured EPSS score (0.302). The practical message: at disclosure time, weight the patch queue by
asset criticality immediately rather than waiting for the exploit signal to mature.

## Reproduce

```bash
pip install -r requirements.txt
cd src
python3 run_evaluation.py   # 25 seeds x 5 noise levels x 9 methods
python3 analyze.py          # hypothesis verdicts
python3 make_figures.py     # figures
```

All randomness is seeded; `results/primary_v1/run_manifest.json` records the seeds, the
maturation and predictor constants, and the corpus snapshot. Development seeds (300, 400 to 424)
are excluded from all reported results.

## Data and integrity

No employer or operational data is used. The fleet is synthetic with public structural priors;
the matured EPSS and KEV signal is resampled from a frozen FIRST EPSS and CISA KEV snapshot
(2026-06-05, 203,174 CVEs). The day-0 exploit observation is generated by a pre-registered
maturation model, not measured against a real EPSS time series. Hypotheses, thresholds, and
seeds were locked before any evaluation-seed result was inspected.
