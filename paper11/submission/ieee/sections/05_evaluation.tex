\section{Evaluation Design}
\label{sec:eval}

\textbf{Primary metric, Mission-Weighted Precision@K (MWP@K).} A pair is a
\emph{Mission-Critical True Positive} (MCTP) iff $\mathrm{EPSS}(c)>0.10$ and
$\mathrm{ACS}(h)>$ the fleet 75th percentile. This mirrors the base scorer's ground-truth
structure but swaps hygiene risk for mission context. $\mathrm{MWP@K}$ is the fraction of
the top-$K$ that are MCTPs, at $K=50,100,250$. The MCTP target uses the \emph{primary}
weighted ACS and is \emph{fixed across all methods}: every ranker, including the
ablations, is scored against the same target, so no method gains a labelling advantage.

\textbf{Secondary metrics.} (i) \emph{Context-blind P@K}, the base scorer's original target
($\mathrm{EPSS}>0.10$ and $\mathrm{HRS}>$P75), used to measure the tradeoff; (ii)
\emph{CWER@K}, the oracle-normalized criticality-weighted exposure captured in the top-$K$,
$\sum_{\text{top-}K}\mathrm{ACS}(h)\cdot\mathbf{1}[\mathrm{EPSS}(c)>0.10]$; (iii)
\emph{NDCG@K} on MCTP labels.

\textbf{Baselines.} EPSS-only, CVSS-only, Random, HRS-only, Context-only (rank by ACS
alone), the base scorer (primary comparison), CAP-G, three context ablations
(noCrit / noZone / noSens), and CAP-G-hwm.

\textbf{Fleet and seeds.} Each seed instantiates the EEHDA synthetic fleet
($\sim$830 hosts) with the context layer above; CVE EPSS/KEV values are resampled from the
real corpus. Evaluation uses 25 seeds (200-224); calibration uses 5 disjoint held-out
seeds.

\textbf{Reporting.} Mean $\pm$ 95\% BCa CI (10{,}000 resamples)~\cite{efron1987bca} over
25 seeds; the evidentiary standard is CI non-overlap, with no null-hypothesis significance
testing. Hypotheses, thresholds, metrics, and
seeds were locked in the pre-registration before any evaluation-seed result was inspected.
